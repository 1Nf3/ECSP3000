\section{Rootkits: Definition \& Context}

Rootkits are typically described as a specialised piece of malware built for persistence \& stealth. They may additionally allow for functionality such as backdoors (cite magic bpf), file hiding or other abilities that give an attacker greater ability for data exfiltration and longevity on a system.

Linux has been chosen for this project due to its relevance and prevalence in cloud \& server environments. Additionally, a wide range of rootkit techniques exist for Linux which will be covered in the following section. As a result many open-source tools exist in order to analyse a system for the presence of a rootkit. This can be a challenging task due to the very nature of a rootkit but is made additionally challening when discussing \textbf{on-host} solutions.
